## 🎯 **نظرة عامة**

منصة **Auto Smart** هي بيئة تطوير متكاملة مصممة بنمط الأسطورة لإنشاء وإدارة مشاريع الويب باستخدام أحدث التقنيات:

- 🔥 **Laravel 11** - إطار العمل الأساسي
- ⚡ **Livewire 3** - التفاعل الديناميكي
- 🗄️ **SQLite** - قاعدة بيانات محلية سريعة  
- 🎨 **Bootstrap 5** - تصميم عصري ومتجاوب
- 🤖 **AI Integration** - ذكاء اصطناعي مدمج

## 🚀 **البدء السريع**

### 📋 **المتطلبات:**
```bash
PHP 8.4+
Composer 2.8+
SQLite 3.46+
```

### ⚡ **التثبيت:**
```bash
# استنساخ المشروع
git clone https://github.com/yourusername/auto-smart.git
cd auto-smart

# إنشاء مشروع جديد
php scripts/create-project.php my-awesome-project

# تشغيل المشروع
php scripts/serve-project.php my-awesome-project
```

### 🎯 **إنشاء مشروع من قالب:**
```bash
# قالب أساسي
php scripts/create-from-template.php basic my-project

# قالب متجر إلكتروني
php scripts/create-from-template.php ecommerce my-store

# قالب لوحة تحكم
php scripts/create-from-template.php dashboard my-dashboard
```
